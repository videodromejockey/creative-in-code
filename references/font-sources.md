# Font sources

Use this file when the project needs a font that is not installed. Do the steps in this order:

1. Use a font that the user supplies, or a brand font from the client's design system.
2. Use an installed font. Check which fonts are installed before you choose.
3. Get a licensed free font from a source in "Licensed sources".

Put each downloaded font in the project folder (for example `fonts/`). Do not install it for the whole system. In the script, record the font name, the source URL and the license.

## Licensed sources

These fonts are free to use, including in work that you publish. Read the license of each font before you use it, because the terms can change.

- **Google Fonts** (fonts.google.com): most fonts use the SIL Open Font License (OFL). Example grotesque: Inter.
- **Fontshare** (fontshare.com), from the Indian Type Foundry: free for personal and commercial use under the ITF Free Font License. Example grotesques: Satoshi, General Sans.
- **Velvetyne** (velvetyne.fr): an open-source foundry. Most fonts use the OFL.
- **Collletttivo** (collletttivo.it): an open-source foundry. Most fonts use the OFL.
- **Adobe Fonts** (fonts.adobe.com): only if the user has a Creative Cloud plan. The fonts are licensed through that plan.

A commercial font is allowed only if the user has a license for it. Ask the user for the local font file.
