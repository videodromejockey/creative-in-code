# Swiss style: sources

`STYLE.md` is a summary of the sources below. Their text and images are not in this repo, because of copyright. This file tells you where to get them.

To build the corpus, use steps 4–7 of `references/new-style.md`:

1. Read each text source. Save it as one markdown file in this folder.
2. Save each reference image in `<work folder>/_research/swiss/images/`.
3. Record in this file the date you read each source.

Each source was last read on 2026-09-28. Check the rights of each source again before you save it. The repo `.gitignore` keeps every file in this folder out of git, except this one.

## Images

- **Wikipedia:** the images in the article are on Wikimedia Commons. The license of each image is on its Commons file page. Open the file page from the image in the article.
- **The Swiss Grid:** the site shows posters by each designer, typeface specimens, and grid overlays on posters (for example *Musica Viva*, 1958). Look at them on the site. Read the site terms before you save any image.
