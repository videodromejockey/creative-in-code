# Swiss style: lessons

Each lesson has a date, a time, a kind and what to do. The kinds are:

- **durable**: a lasting preference or rule.
- **situational**: true for that brief only. Use it as a guide for similar briefs.
- **perishable**: true for now only, for example a library bug or a missing font. Check that it is still true before you rely on it.

Add new lessons at the end of the correct section.
